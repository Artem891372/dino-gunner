## О проекте

Браузерная игра-раннер: динозаврик бежит по бесконечным биомам, отстреливается от врагов, подбирает оружие и держится как можно дольше. Играть можно вручную или включить **автономного ИИ-бота**, который сканирует сектор впереди, сам прыгает через препятствия, приседает под летящими врагами и наводит ствол точно в цель.

Весь игровой мир — процедурный, все звуки, музыка и графика синтезируются на лету: ни одного внешнего спрайта или аудиофайла.

## Возможности

### 🤖 Автономный ИИ-бот
- Сканирование препятствий и врагов впереди, расчёт точки прыжка с учётом скорости и ширины препятствия.
- Наведение ствола по геометрии, реакция с задержкой, управляемые промахи и паника — настраиваются в панели инспектора.
- Живая телеметрия: статус, дистанция до угрозы, угол наведения, траектория и уверенность.

### 🔫 Оружие и прогрессия
- Четыре ствола: штурмовая винтовка, лазерный бластер, боевой дробовик, плазменная пушка.
- Светящиеся ящики с оружием появляются на пути — пробеги сквозь, чтобы сменить ствол на случайный.
- Комбо-серии до x8: множитель очков, растущий звук и усиленный хит-стоп.

### 🌍 Живой мир
- **Пять биомов** — поля, лес, горы, холмы и пустыня — плавно сменяют друг друга и подбираются под погоду.
- **Цикл дня и ночи**: солнце восходит и садится по дуге, ночью плывёт полумесяц, небо и палитра меняются.
- **Погода**: дождь, снег и песчаная буря приходят по таймеру и кроссфейдятся; в снегопад вершины гор покрываются шапками.
- Параллакс в несколько слоёв: дальние силуэты плывут медленнее ближних, биомы перетекают друг в друга за несколько секунд.

### 🌊 Волны и боссы
- Режиссёр волн чередует затишье, плотный поток, воздушный налёт и полосу препятствий.
- Каждые несколько волн — **босс**, тип которого зависит от биома: усиленный враг с большим запасом HP, аурой и надписью BOSS.
- Препятствия и враги зависят от биома: кактусы и песчаные пауки в пустыне, пни и рапторы в лесу, кибер-черепа и стервятники в горах.

### ✨ Juice
- Хит-стоп на убийствах, тряска камеры, пиксельные взрывы, гильзы, счётчики комбо и всплывающие очки.
- Герой сам меняет окрас под среду: режим «АВТО» подбирает скин по биому, погоде и времени суток, у каждого скина свой аксессуар (шляпа следопыта, каска, кибер-визор, корона фараона, шипастый шлем).
- Весь интерфейс автоматически уходит в тёмную тему с закатом и возвращается к светлой на рассвете.

### 🎵 Звук и музыка
- 8-битные выстрелы, прыжки, попадания и смерти — всё на Web Audio API.
- Фоновая музыкальная петля с битом (кик, снейр, клэп, хэты, томы, бас и арп), темп ускоряется вместе с бегом.

### 🎬 Для записи видео
- **Чистый режим [C]** — скрывает весь интерфейс, оставляя игру и счёт.
- Кнопки и авто-режимы: тема, музыка, скин, оружие.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Space` / `↑` / `W` | Прыжок |
| `↓` / `S` | Присед |
| `F` / `E` / `Enter` / мышь | Выстрел (в ручном режиме — прицеливание курсором) |
| `A` | Авто-бот ↔ ручной режим |
| `1`–`4` | Выбор оружия |
| `T` | Тема (выключает авто-тему) |
| `B` | Музыка вкл/выкл |
| `M` | Общий звук вкл/выкл |
| `P` | Пауза |
| `C` | Чистый экран для записи |

## Технологии

| Слой | Что используется |
| --- | --- |
| Фронтенд | React 19, TypeScript, Vite 7 |
| Графика | Canvas 2D, пиксельная отрисовка без спрайт-листов |
| Стили | Tailwind CSS 4 |
| Звук | Web Audio API (синтез 8-бита на лету) |
| UI-иконки | lucide-react, canvas-confetti |
| Деплой | GitHub Actions → GitHub Pages |

## Запуск локально

```bash
npm install
npm run dev       # dev-сервер Vite
npm run build     # прод-сборка в dist/
npm run preview   # локальный предпросмотр сборки
```

Требуется Node.js 20+.

## Деплой

Каждый пуш в `main` автоматически собирает проект и публикует его на GitHub Pages через workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

## Структура проекта

```
src/
├── game/
│   ├── engine.ts       — игровой цикл, физика, спавн, волны, биомы, погода, комбо
│   ├── aiController.ts — автономный бот: сканирование, наведение, прыжки и приседы
│   ├── sprites.ts      — пиксельная отрисовка героя, врагов, биомов, погоды и эффектов
│   ├── audio.ts        — 8-битный синтезатор звуков и музыкальная петля
│   └── types.ts        — общие типы мира и сущностей
├── components/         — HUD, инспектор ИИ, справка, оверлей смерти, панели настроек
└── App.tsx             — состояние приложения, горячие клавиши, чистый режим
```
